# Ostraka

A free Koine Greek study app for vocabulary, paradigms and translation: spaced-repetition review,
mastery-based study sessions (flashcards, typing, multiple choice, English → Greek,
drawing, matching board), 68 built-in paradigm charts, and a Translate mode that walks you
through a sentence the way you'd translate it by hand (parse each word, build the skeleton,
then write the whole sentence), Greek → English or English → Greek.

**Use it:** open the site in any browser. On iPhone or iPad, tap Share → Add to Home Screen
to install it like an app (it works offline after the first visit).

Words, sentences and progress are saved on your own device. Add your own vocabulary under
**Add Words** and your own sentences under **Translate → Import**.
